Solving First Order ODEs

Developed a numerical simulation of a damped pendulum in Octave/MATLAB by solving nonlinear ordinary differential equations (ODEs). The project involved converting a second-order ODE into a system of first-order equations, implementing numerical solution techniques using `lsode`, generating displacement and velocity plots, and creating a pendulum motion animation to visualize the transient dynamics of the system.

Tailor Table Method Explained

Derived and implemented fourth-order finite difference schemes for approximating the second derivative using central, right-skewed, and left-skewed formulations in Octave/MATLAB. The project involved analytical derivation using Taylor series expansion, solving coefficient matrices through LU decomposition, and validating numerical accuracy through error analysis and comparison with analytical solutions. The study also examined stencil behavior, boundary applicability, and the performance of schemes in diffusion- and convection-dominated problems.
